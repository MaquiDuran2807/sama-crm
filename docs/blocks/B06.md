# Block 6: Refactorización y Mejora del Dashboard Kanban del CRM

**Fecha:** Mayo 2026  
**Objetivo:** Refactorizar el dashboard Kanban para mejorar mantenibilidad, agregar funcionalidades avanzadas y mantener la estética de lujo.

---

## Resumen de Cambios

Este bloque implementa las siguientes mejoras al dashboard Kanban del CRM de SAMA:

1. ✅ **Separación de estáticos** (CSS y JavaScript)
2. ✅ **Herencia de plantillas** (base.html)
3. ✅ **Bordes dinámicos por etapa** (CSS variables)
4. ✅ **Drag & Drop** entre columnas con sincronización API
5. ✅ **Tema claro/oscuro** con persistencia en localStorage
6. ✅ **Responsive design** mantenido en todas las resoluciones
7. ✅ **Accesibilidad** mejorada (ARIA labels, skip links)

### 2. CSS: `crm/static/crm/css/dashboard.css`

**Características principales:**

- **Variables CSS globales** (`:root`) para fácil personalización
- **Tema claro** con `body.theme-light` que redefine todas las variables
- **Soporta ambos temas** sin necesidad de CSS separado
- **Bordes dinámicos** usando CSS variable `--stage-color` en `.lead-card`
- **Drag & Drop feedback** con clases `.dragging` y `.drag-over`
- **Transiciones suaves** y animaciones (`@keyframes shimmer`)
- **Responsive design** con breakpoints: 1024px, 768px, 480px
- **Accesibilidad** con skip links y estilos focus

**Ejemplo de colores dinámicos:**

```css
.lead-card {
    border-left: 4px solid var(--stage-color, #64748b);
}

/* En el HTML se pasa como estilo en línea */
style="--stage-color: {{ stage.color|default:'#64748b' }};"
```

**Paleta de colores:**

|----------|--------|-------|
| Fondo | #0a0f1e | #f9fafb |

### 3. JavaScript: `crm/static/crm/js/dashboard.js`

**Módulos y funcionalidades:**

#### a) **Tema Claro/Oscuro** (`initThemeToggle()`)
- Lee localStorage con clave `sama-crm-theme`
- Aplica clase `theme-light` al `<body>`
- Botón toggle en el header (#theme-toggle)
- Cambia icono de ☀️ a 🌙 según tema actual

```javascript
const savedTheme = localStorage.getItem('sama-crm-theme') || 'dark';
applyTheme(savedTheme);  // dark | light
```

#### b) **Búsqueda de Leads** (`filterLeads()`)
- Filtra en tiempo real por nombre, teléfono, producto
- Oculta leads que no coinciden
- Actualiza contadores de columnas dinámicamente
- Botón de limpiar búsqueda

#### c) **Drag & Drop** (`initDragDrop()`)
- **Evento `dragstart`:** Marca la tarjeta como "arrastrando"
- **Evento `dragover`:** Detecta zona de drop (columna destino)
- **Evento `drop`:** 
  - Obtiene lead ID y nueva etapa
  - Mueve tarjeta visualmente (optimista)
  - Ejecuta PATCH a `/api/crm/leads/{id}/?tenant_slug=...`
  - Revertir si falla la API

```javascript
fetch(url, {
    method: 'PATCH',
    headers: {
        'Content-Type': 'application/json',
        'X-CSRFToken': getCookie('csrftoken'),
    },
    body: JSON.stringify({ current_stage: newStage }),
})
```

#### d) **Gestión de Columnas** (`updateColumnCounts()`)
- Actualiza contadores de leads por columna
- Observable con MutationObserver para cambios dinámicos

**Variables de configuración:**

```javascript
const CONFIG = {
    API_BASE: '/api/crm/leads/',
    THEME_STORAGE_KEY: 'sama-crm-theme',
    DRAG_FEEDBACK_CLASS: 'dragging',
    DRAG_OVER_CLASS: 'drag-over',
};
```

## Funcionalidades Nuevas

### ✨ Drag & Drop

**Flujo:**

1. Usuario arrastra una tarjeta (`.lead-card` con `draggable="true"`)
2. Suelta en una columna destino (`.kanban-column`)
3. JavaScript captura `drop` event
4. Envía PATCH a `/api/crm/leads/{lead_id}/?tenant_slug=...`
5. En caso de éxito: tarjeta se mantiene en nueva posición
6. En caso de error: tarjeta revierte a posición original

**API esperada:**

```
PATCH /api/crm/leads/{id}/?tenant_slug=tenant_slug
Content-Type: application/json

{
    "current_stage": "Negociación"
}
```

**Respuesta:**

```json
{
    "id": 1,
    "current_stage": "Negociación",
    "contact_name": "Juan Pérez",
    ...
}
```

### 🌙 Tema Claro/Oscuro

**Funcionamiento:**

1. Botón toggle en header (icono ☀️/🌙)
2. Click alterna clase `theme-light` en `<body>`
3. localStorage guardar preferencia con clave `sama-crm-theme`
4. Al recargar, se aplica tema guardado automáticamente

**Variables CSS por tema:**

```css
/* Tema oscuro (default) */
:root {
    --color-dark-bg: #0a0f1e;
    --color-text-primary: #e0e0e0;
}

/* Tema claro */
body.theme-light {
    --color-dark-bg: #f9fafb;
    --color-text-primary: #1f2937;
}
```

**Persistencia:**

```javascript
localStorage.setItem('sama-crm-theme', 'light');  // Guardar
const theme = localStorage.getItem('sama-crm-theme');  // Recuperar
```

## Accesibilidad

### ARIA Attributes

- `role="banner"` en header
- `role="main"` en main container
- `role="search"` en search container
- `role="region"` en kanban columns
- `aria-label` en botones y elementos interactivos
- `aria-labelledby` en stats cards

### Skip Link

```html
<a href="#main-content" class="skip-link">Saltar al contenido principal</a>
```

- Visible solo al hacer focus (Tab)
- Lleva directo al contenido principal
- Cumple WCAG 2.1 Level A

### Keyboard Navigation

- **Escape:** Limpia búsqueda
- **Tab:** Navega entre elementos
- **Enter:** En tarjetas (ya que son `<a>` tags)

## Notas de Diseño

### Decisiones de Arquitectura:

1. **CSS Variables en lugar de SCSS:** Mantener simplicidad, evitar build step
2. **Vanilla JavaScript:** Sin dependencias, rendimiento, compatibilidad
3. **Template inheritance:** Facilita agregar nuevas páginas CRM
4. **localStorage para tema:** Persisten sin servidor, rápido
5. **PATCH en lugar de PUT:** Actualización granular, mejor para API

### Consideraciones de UX:

- El tema se aplica **globalmente** (base.html) para coherencia
- El drag & drop es **optimista** (mejora percepción de velocidad)
- Los contadores **se actualizan dinámicamente** sin reload
- La búsqueda es **instantánea** (no hay debounce, input es rápido)
