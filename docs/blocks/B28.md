# B28 — Visualización de metas (KPI) en el dashboard de analíticas

## User Story
Como usuario del CRM, quiero ver mi progreso hacia las métricas definidas (KPIs) directamente en el dashboard de analíticas, con líneas de referencia en los gráficos y tarjetas resumen.

## Descripción
Se extiende el dashboard de analíticas (`analytics.html`) para mostrar el progreso hacia las metas definidas por el tenant. Esto incluye:

1. **Tarjetas de metas** (`renderGoalCards`): Tarjetas tipo summary-card con barra de progreso lineal, valor actual vs meta, y color de estado.
2. **Línea de referencia en el gráfico de timeline** (`chartjs-plugin-annotation`): Línea horizontal punteada verde que indica la meta mensual de leads.
3. **Indicador de meta en el embudo**: Inscripción "Meta: X" en el summary del funnel + badge flotante sobre la barra de meta de conversiones.

## Modelo KpiTarget

```python
class KpiTarget(models.Model):
    tenant = models.ForeignKey(Tenant, on_delete=models.CASCADE, related_name="kpi_targets")
    name = models.CharField(max_length=100)
    metric_type = models.CharField(max_length=30, choices=MetricType.choices)  # leads, conversions, conversion_rate, avg_days
    target_value = models.FloatField()
    period_type = models.CharField(max_length=20, choices=PeriodType.choices, default=PeriodType.MONTHLY)
    is_active = models.BooleanField(default=True)
```

## Flujo de datos

```
analytics_api (views.py)
  ├─ Lee KpiTarget.objects.filter(tenant=tenant, is_active=True)
  ├─ Calcula current_value según el período seleccionado (mensual/trim/semanal/diario)
  ├─ Devuelve kpi_targets: [{name, metric_type, target_value, current_value, progress_percent}]
  └─ Devuelve current_period_label: "May 2026"
```

## Frontend — Goal Cards

- Renderizadas en `renderGoalCards(kpiTargets, periodLabel)`
- Si no hay metas: mostrar estado vacío con enlace "Configurar metas"
- Barra de progreso lineal con color según estado:
  - Verde (#10b981) si progress >= 80%
  - Amarillo (#f59e0b) si progress >= 50%
  - Rojo (#ef4444) si progress < 50%

## Frontend — Timeline Annotation

- Cargar `chartjs-plugin-annotation@3.0.1` desde CDN antes de analytics.js
- `buildAnnotations()` genera configuración de anotación para meta de "leads"

## Limitaciones conocidas

1. Las metas son a nivel tenant, no por campaña o fuente
2. El cálculo de `current_value` usa el mismo filtro de período que la consulta principal
3. No hay endpoint CRUD para gestionar metas (se gestionan vía admin de Django)
4. El badge del funnel usa posicionamiento CSS absoluto sobre el canvas (no se recalcula al redimensionar)
