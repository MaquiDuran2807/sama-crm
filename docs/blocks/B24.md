# Block B24 — Sistema de Etiquetas (Tags) para Leads

## User Story

Como usuario del CRM, quiero agregar, eliminar y crear etiquetas para un lead desde la página de detalle, para que pueda categorizar y priorizar mis leads visualmente.

---

## Estado Actual

Los modelos `Tag` y `LeadTag` ya existen en `crm/domain/models.py`:
- **Tag**: tenant FK, name, color, is_predefined, created_at. Unique_together (tenant, name).
- **LeadTag**: lead FK, tag FK, created_at. Unique_together (lead, tag).

Los endpoints API ya están implementados en `crm/interfaces/views.py`:
- `GET /api/crm/tenants/{slug}/tags/` — Lista todas las etiquetas del tenant
- `POST /api/crm/tenants/{slug}/tags/` — Crea una etiqueta custom
- `DELETE /api/crm/tenants/{slug}/tags/{id}/` — Elimina etiqueta (solo si no es predefinida)
- `POST /api/crm/leads/{id}/add_tag/` — Asigna una etiqueta al lead
- `POST /api/crm/leads/{id}/remove_tag/` — Elimina una etiqueta del lead

Los serializadores `TagSerializer` y `LeadTagSerializer` ya están implementados en `crm/interfaces/serializers.py`.

## API Endpoints Documentados

### 1. Listar etiquetas del tenant

**GET** `/api/crm/tenants/{slug}/tags/`

**Response (200)**:
```json
[
  {
    "id": 1,
    "name": "VIP",
    "color": "#ff0000",
    "is_predefined": false,
    "created_at": "2026-05-10T12:00:00Z"
  },
  {
    "id": 2,
    "name": "Urgente",
    "color": "#ff6600",
    "is_predefined": true,
    "created_at": "2026-01-01T00:00:00Z"
  }
]
```

### 2. Crear etiqueta

**POST** `/api/crm/tenants/{slug}/tags/`

**Body**:
```json
{
  "name": "Nuevo Lead",
  "color": "#3498db"
}
```

**Response (201)**:
```json
{
  "id": 3,
  "name": "Nuevo Lead",
  "color": "#3498db",
  "is_predefined": false,
  "created_at": "2026-05-11T10:30:00Z"
}
```

**Response (400)** — Nombre duplicado:
```json
{
  "name": ["Ya existe una etiqueta con este nombre para este tenant."]
}
```

### 3. Eliminar etiqueta

**DELETE** `/api/crm/tenants/{slug}/tags/{id}/`

**Response (204)**: Sin contenido — Eliminación exitosa.

**Response (403)** — Etiqueta predefinida:
```json
{
  "detail": "No se pueden eliminar etiquetas predefinidas."
}
```

### 4. Asignar etiqueta a lead

**POST** `/api/crm/leads/{id}/add_tag/`

**Body**:
```json
{
  "tag_id": 5
}
```

**Response (201)**:
```json
{
  "id": 10,
  "tag_id": 5,
  "tag_name": "VIP",
  "tag_color": "#ff0000",
  "created_at": "2026-05-11T11:00:00Z"
}
```

**Response (400)** — tag_id faltante:
```json
{
  "detail": "tag_id es obligatorio."
}
```

### 5. Eliminar etiqueta del lead

**POST** `/api/crm/leads/{id}/remove_tag/`

**Body**:
```json
{
  "tag_id": 5
}
```

**Response (200)**:
```json
{
  "detail": "Etiqueta eliminada."
}
```

**Response (404)** — Relación no existente:
```json
{
  "detail": "Etiqueta no encontrada."
}
```

## UI: Componentes en lead_detail.html

### Sección "Etiquetas"

Se agregó una nueva card "Etiquetas" después de la sección "Origen del lead" (líneas 47-58 del archivo original).

**Elementos de la UI:**

1. **Badges de etiquetas actuales**: Muestra las etiquetas asignadas al lead como badges Bootstrap 5 con fondo del color de la etiqueta y texto con contraste automático.

2. **Botón "Agregar etiqueta"**: Abre un dropdown con las etiquetas del tenant que no están asignadas al lead.

3. **Opción "Nueva etiqueta"**: En el dropdown, última opción que muestra un formulario inline para crear y asignar una nueva etiqueta.

4. **Botón de eliminar (×)**: En cada badge, permite quitar la etiqueta del lead.

### Estilos

- Los badges usan `background-color` igual al color de la etiqueta.
- El texto usa función helper `getContrastColor(hexColor)` para determinar blanco o negro según luminosidad.
- Compatible con tema oscuro/claro mediante variables CSS.

## Cómo Testear Manualmente

### Prerrequisitos
1. Ejecutar `python manage.py seed_dynamic` para crear datos de prueba.
2. Navegar a `/crm/{tenant_slug}/leads/{lead_id}/`.

### Verificar listado de etiquetas
1. Observar la sección "Etiquetas" en el detalle del lead.
2. Si el lead tiene etiquetas asignadas, aparecen como badges coloreados.
3. Si no hay etiquetas, mostrar "Sin etiquetas".

### Agregar etiqueta existente
1. Hacer click en el botón "+ Agregar etiqueta".
2. Ver dropdown con etiquetas del tenant no asignadas al lead.
3. Click en una etiqueta → se asigna al lead y actualiza la lista.

### Crear nueva etiqueta
1. En el dropdown, click en "+ Nueva etiqueta".
2. Mostrar formulario inline con:
   - Input de texto para nombre
   - Color picker con color aleatorio por defecto
3. Click en "Crear y asignar" → crea la etiqueta y la asigna al lead.

### Eliminar etiqueta
1. Click en el botón "×" en un badge de etiqueta.
2. Llamar al endpoint remove-tag y actualizar la lista.

### VerificarTema claro/oscuro
1. Cambiar entre tema oscuro y claro.
2. Los badges deben mantener el contraste correcto en ambos temas.

## Limitaciones Conocidas

- Las etiquetas predefinidas solo pueden ser eliminadas desde el backend (admin), no desde la UI.
- El color picker sugiere un color aleatorio pero no valida contraste con el fondo de la card.
- No hay límite máximo de etiquetas por lead (podría ser necesario agregar validación).
- Las etiquetas no tienen lógica de negocio adicional (ej: no hay colores por defecto para tipos específicos).
