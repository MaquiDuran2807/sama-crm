# Block B24 — Sistema de Etiquetas (Tags) para Leads

## User Story

Como usuario del CRM, quiero agregar, eliminar y crear etiquetas para un lead desde la página de detalle, para que pueda categorizar y priorizar mis leads visualmente.

---

## Estado Final (Actualizado 2026-05-11)

Los modelos `Tag` y `LeadTag` ya existen en `crm/domain/models.py`:
- **Tag**: tenant FK, name, color, is_predefined, created_at. Unique_together (tenant, name).
- **LeadTag**: lead FK, tag FK, created_at. Unique_together (lead, tag).

Los endpoints API están implementados en `crm/interfaces/views.py`:
- `GET /api/crm/tenants/{slug}/tags/` — Lista todas las etiquetas del tenant
- `POST /api/crm/tenants/{slug}/tags/` — Crea una etiqueta custom (con validación de nombre único)
- `DELETE /api/crm/tenants/{slug}/tags/{id}/` — Elimina etiqueta (solo si no es predefinida)
- `POST /api/crm/leads/{id}/add_tag/` — Asigna una etiqueta al lead
- `POST /api/crm/leads/{id}/remove_tag/` — Elimina una etiqueta del lead

## API Endpoints Documentados

### 1. Listar etiquetas del tenant

**GET** `/api/crm/tenants/{slug}/tags/`

**Response (200)**:
```json
[
  { "id": 1, "name": "VIP", "color": "#ff0000", "is_predefined": false, "created_at": "2026-05-10T12:00:00Z" },
  { "id": 2, "name": "Urgente", "color": "#ff6600", "is_predefined": true, "created_at": "2026-01-01T00:00:00Z" }
]
```

### 2. Crear etiqueta

**POST** `/api/crm/tenants/{slug}/tags/`

**Body**: `{ "name": "Nuevo Lead", "color": "#3498db" }`

**Response (201)**: `{ "id": 3, "name": "Nuevo Lead", "color": "#3498db", "is_predefined": false, "created_at": "..." }`

**Response (400)** — Nombre duplicado:
```json
{ "name": ["Ya existe una etiqueta con este nombre para este tenant."] }
```

### 3. Eliminar etiqueta

**DELETE** `/api/crm/tenants/{slug}/tags/{id}/`

**Response (204)**: Sin contenido.

**Response (403)** — Etiqueta predefinida:
```json
{ "detail": "No se pueden eliminar etiquetas predefinidas." }
```

### 4. Asignar etiqueta a lead

**POST** `/api/crm/leads/{id}/add_tag/`

**Body**: `{ "tag_id": 5 }`

**Response (201)**: `{ "id": 10, "tag_id": 5, "tag_name": "VIP", "tag_color": "#ff0000", "created_at": "..." }`

### 5. Eliminar etiqueta del lead

**POST** `/api/crm/leads/{id}/remove_tag/`

**Body**: `{ "tag_id": 5 }`

**Response (200)**: `{ "detail": "Etiqueta eliminada." }`

**Response (404)**: `{ "detail": "Etiqueta no encontrada." }`

## UI: Modal de Gestión de Etiquetas

### Cambios respecto a la versión anterior

1. **Reemplazo del dropdown por modal**: Ahora al hacer clic en "Gestionar" se abre un modal Bootstrap más atractiva y funcional.

2. **Tres secciones en el modal**:
   - **Etiquetas actuales**: Muestra los badges de las etiquetas ya asignadas con botón para eliminar (×).
   - **Crear nueva etiqueta**: Formulario con input de texto, color picker con selector de color y previsualización del color en hex.
   - **Etiquetas disponibles**: Muestra todas las etiquetas del tenant que NO están asignadas al lead, como botones clicables.

3. **Mejoras de UX**:
   - El color picker muestra el código hex en tiempo real.
   - Al crear una etiqueta, se limpia el input automáticamente.
   - No hay scroll undesiredo al abrir el modal.

### Estilos

- Los badges usan `background-color` igual al color de la etiqueta.
- El texto usa función helper `getContrastColor(hexColor)` para determinar blanco o negro según luminosidad.
- Compatible con tema oscuro/claro mediante variables CSS.
- Botones de etiquetas disponibles con efecto hover (escala).

## Cómo Testear Manualmente

### Prerrequisitos
1. Ejecutar `python manage.py seed_dynamic` para crear datos de prueba.
2. Navegar a `/crm/{tenant_slug}/leads/{lead_id}/`.

### Verificar listado de etiquetas
1. Observar la sección "Etiquetas" en el detalle del lead.
2. Si el lead tiene etiquetas asignadas, aparecen como badges coloreados.
3. Si no hay etiquetas, mostrar "Sin etiquetas" con botón "Gestionar".

### Abrir modal de etiquetas
1. Hacer clic en el botón "Gestionar" (icono de tags).
2. Se abre el modal con las tres secciones.

### Asignar etiqueta existente
1. En el modal, sección "Etiquetas disponibles", hacer clic en una etiqueta.
2. La etiqueta se asigna al lead y aparece en "Etiquetas actuales".
3. La etiqueta desaparece de "Etiquetas disponibles".

### Crear nueva etiqueta
1. En el modal, sección "Crear nueva etiqueta":
   - Escribir el nombre en el input.
   - Seleccionar un color con el picker (muestra el código hex).
2. Clic en "Crear y asignar".
3. Se crea la etiqueta para el tenant y se asigna al lead automáticamente.

### Eliminar etiqueta
1. En el modal o en la vista principal, hacer clic en el botón "×" en un badge.
2. Confirmar en el diálogo.
3. La etiqueta se elimina del lead.

### VerificarTema claro/oscuro
1. Cambiar entre tema oscuro y claro.
2. Los badges deben mantener el contraste correcto en ambos temas.

## Limitaciones Conocidas

- Las etiquetas predefinidas solo pueden ser eliminadas desde el backend (admin), no desde la UI.
- No hay límite máximo de etiquetas por lead.
- Las etiquetas predefinidas no se muestran de manera especial en la UI (solo por `is_predefined` en la API).
