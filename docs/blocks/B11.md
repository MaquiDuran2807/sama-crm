# Block 11: Seed CRM dinámico con datos realistas

**Fecha:** Mayo 2026

## Objetivo del bloque

Reescribir el comando `seed_solar_client` para generar datos de prueba dinámicos y realistas que permitan probar el sistema CRM con volúmenes significativos de datos:

- 50 contactos con nombres reales colombianos
- 100+ leads distribuidos a lo largo del año 2026
- LeadSource para cada lead con datos UTM variados
- Reportes de seguimiento diarios

## Alcance

- `crm/management/commands/seed_solar_client.py`
- `crm/domain/models.py` (nuevo modelo DailyFollowupReport)
- `crm/migrations/0003_add_daily_followup_report.py`
- `docs/blocks/B11.md`

## Decisiones de diseño

### Nombres realistas colombianos
- 20 nombres femeninos y 20 masculinos de uso frecuente en Colombia
- 15 apellidos comunes colombianos
- Combinación aleatoria: nombre + apellido = nombre completo
- Emails generados como `nombre.apellido@example.com`

### Teléfonos realistas
- Formato colombiano: +57 300 XXX XXXX
- Prefijo 300 seguido de 7 dígitos aleatorios

### Distribución de leads
- 110 leads (más de los 100 mínimos requeridos)
- Distribuidos entre los 50 contactos (algunos tienen 2-3 leads)
- Fechas de creación entre 2026-01-01 y hoy
- `last_contacted_at` puede ser null (30% de los casos) o reciente

### Pipeline stages
Se usa el pipeline del tenant con las etapas:
- Lead
- Calificación
- Cotización Enviada
- Seguimiento
- Cerrado Ganado (is_closed=True, closed_result='won')
- Cerrado Perdido (is_closed=True, closed_result='lost')

### Datos UTM aleatorios
Cada LeadSource incluye:
- platform: meta, google, tiktok, web, referral
- utm_source: facebook_ads, google_ads, tiktok_ads, organic, newsletter, referral_program
- utm_medium: cpc, social, email, organic
- utm_campaign: campaign_verano_2026, promo_baterias, etc.
- landing_page_url: /productos/paneles, /promociones/kit-solar, etc.

### Semilla de reproducibilidad
- `random.seed(42)` al inicio del comando
- Datos reproducibles entre ejecuciones
- Comando idempotente: usa `get_or_create` y `update_or_create`

### Modelo DailyFollowupReport
- Reporte diario de seguimiento de leads fríos
- Tipos: mañana y tarde
- Incluye lista de lead_ids a seguir

## Resultado esperado

Después de ejecutar `python manage.py seed_solar_client`:

```
Seed completado: seed_solar_client
50 contactos creados
110 leads creados
110 LeadSource creados
~200 actividades creadas
3 reportes de seguimiento creados
Leads por etapa: Lead: 20, Calificacion: 14, ...
```
