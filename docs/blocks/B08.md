## Campos de API nuevos en analytics

La API `GET /api/crm/tenants/{slug}/analytics/` ahora devuelve campos adicionales:

### leads_by_region

```json
[
  {
    "department": "Antioquia",
    "total": 45,
    "won": 12,
    "conversion_rate": 26.7
  }
]
```

- `department`: nombre del departamento colombiano
- `total`: total de leads en el departamento
- `won`: leads cerrados como ganados
- `conversion_rate`: porcentaje de conversion

## Componentes del dashboard

### 1. Tarjetas de estadisticas (6 cards)

- `stat-total`: Total de leads
- `stat-conversion`: Tasa de conversion (%)
- `stat-avg`: Dias promedio al cierre
- `stat-week`: Leads esta semana
- `stat-won`: Cerrados Ganados
- `stat-lost`: Cerrados Perdidos

### 2. Mapa de Colombia (#colombia-map + #colombia-map-container)

- SVG con paths para cada departamento colombiano
- Colores segun volumen de leads:
  - 0 leads = gris (#64748b)
  - bajo = azul claro (#dbeafe)
  - medio = azul (#60a5fa)
  - alto = azul oscuro (#003366)
- Tooltip en hover con nombre del departamento, leads totales, ganados y tasa de conversion
- Leyenda integrada

**Departamentos incluidos:** Antioquia, Cundinamarca, Valle del Cauca, Atlantico, Santander, Boyaca, Narino, Cauca, Tolima, Huila, Magdalena, Caldas, Cordoba, Sucre, Bolivar, Cesar, Norte de Santander, Caqueta, Meta, Casanare, Risaralda, Quindio, Choco, La Guajira, Vichada, Guainia, Vaupes, Guaviare, Putumayo, Amazonas, San Andres.

**Matching de datos:** Se usa `normalizeDeptKey()` para convertir nombres de API a keys SVG (lowercase, sin acentos, guiones bajos).

### 3. Tabla regional (#region-table-body)

- Columnas: Departamento, Leads, Ganados, Tasa, Barra de conversion
- Barra de progreso proporcional a `conversion_rate`
- Colores de barra:
  - Verde (#2ec27e): >15%
  - Naranja (#f5a623): >5%
  - Rojo (#ef4444): <=5%

### 4. Embudo de ventas (#funnel-chart + #funnel-summary)

- Grafico de barras horizontal usando Chart.js
- Gradient de colores SAMA: #003366 (top) a #FF9933 (bottom)
- Muestra cuenta y porcentaje por etapa
- Resumen total debajo del grafico

### 5. Mix de fuentes mensual (#source-mix-chart)

- Grafico de barras apiladas (stacked bar chart)
- Eje X: meses (formato "Ene 2026")
- Stacks: meta (#1877F2), google (#4285F4), tiktok (#ff0050), web (#64748b), referral (#FF9933)
- Leyenda en la parte superior

### 6. Timeline (#timeline-chart)

- Grafico de lineas multiple
- Lineas:
  - Leads nuevos: azul (#3b82f6), area rellena
  - Cerrados Ganados: verde (#2ec27e), lineas punteadas
  - Cerrados Perdidos: rojo (#ef4444), lineas punteadas
  - Cotizaciones Enviadas: naranja (#f5a623), lineas punteadas finas
- Agrupacion automatica por dia (<45 dias) o por mes (>45 dias)
- Tension 0.3 para suavidad

### 7. Barra de filtros

- **Navegacion de periodo:** prev/next con arrows y localStorage offset tracking
- **Botones de rango:** 7 dias, 30 dias, 90 dias, 365 dias, Todo (data-days)
- **Filtro de fuente:** select con opciones de plataforma

## Decisiones clave

1. **SVG inline vs imagen:** Se usan paths SVG directos en JavaScript para permitir hover y tooltips dinamicos.
2. **Matching de departamentos:** Se normalizan nombres removiendo acentos y espacios para hacer match entre API y SVG.
3. **Destruccion de charts:** Todos los charts se almacenan en objeto global `charts` y se destruyen antes de recrear (evita memory leaks).
4. **Theme support:** `applyTheme()` re-renderiza todos los charts con colores apropiados segun localStorage.
5. **Eventos de tema:** Se escuchan tanto `storage` (otras pestañas) como `theme-changed` (misma pestaña).

## Endpoints utilizados

- `GET /api/crm/tenants/{slug}/analytics/?days=N&offset=O&source=X`

## Variables de tema

- **Dark theme:** bg=#1a1d24, surface=#21252e, text=#d4d8e3
- **Light theme:** bg=#f5f6f8, surface=#ffffff, text=#1a1d24

## Como verificar

1. Ir a `/crm/<tenant>/analytics/`
2. Verificar que las 6 stat cards muestren valores correctos
3. Hacer click en diferentes rangos de tiempo (7/30/90/365/dias)
4. Usar las flechas prev/next para navegar periodos
5. Hover sobre el mapa para ver tooltips
6. Verificar tabla regional con barras de colores
7. Verificar embudo con gradient SAMA
8. Verificar stacked bars de fuentes mensuales
9. Verificar timeline con 4 lineas
10. Cambiar tema (claro/oscuro) y verificar que charts se actualicen

## Limitaciones conocidas

- El mapa SVG es una representacion simplificada; no es geograficamente exacto
- Algunos departamentos pueden no tener datos y se muestran en gris
- Los colores del mapa no se actualizan automaticamente con cambio de tema (por diseno)
