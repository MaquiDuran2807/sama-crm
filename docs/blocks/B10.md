# Block 10: Dashboard de analíticas con gráficos — HU-08

**Fecha:** Mayo 2026

## User Story implementada

### HU-08: Dashboard de analíticas con gráficos

User Story: As a CRM user, I want to see a metrics dashboard with funnel, pie, and time-series charts, and filter by date range and source, so I can analyze my sales pipeline performance visually.

## Archivos modificados/creados

- `crm/interfaces/views.py` — `CrmAnalyticsTemplateView`, `analytics_api` (función @api_view)
- `crm/templates/crm/analytics.html` — plantilla completa con filtros, tarjetas de resumen y 3 gráficos Chart.js
- `crm/interfaces/urls.py` — ruta API `/api/crm/tenants/<slug>/analytics/`
- `crm/web_urls.py` — ruta HTML `/crm/<tenant>/analytics/`
- `crm/templates/crm/base.html` — enlace "Analíticas" en el dropdown del usuario
- `docs/blocks/B10.md` — este archivo

## Decisiones clave

- La API es una `@api_view` (no action de ViewSet) porque consulta datos agregados a nivel de tenant, no recursos individuales de lead.
- Se фильтрует por `created_at__gte` para limitar el rango temporal de los datos.
- Filtro por `source__platform` via join con `LeadSource` (solo incluye leads que tienen fuente asignada).
- El funnel se ordena según el `order` definido en `pipeline_config.stages`, con fallback para etapas fuera del pipeline.
- `avg_days_to_close` usa expresión SQL `EXTRACT(EPOCH ...)` para calcular diferencia en días directamente en la base de datos.
- Los gráficos se recrean completamente cuando cambia el tema (escuchando el evento `storage` de localStorage).

## Endpoint API

### `GET /api/crm/tenants/{tenant_slug}/analytics/`

**Query params:**
- `days` (int, default 30): filtro de días hacia atrás desde hoy.
- `source` (str, opcional): filtra por plataforma (`meta`, `google`, `tiktok`, `web`, `referral`).

**Respuesta:**
```json
{
  "funnel": [
    {"stage": "Lead", "count": 12},
    {"stage": "Calificación", "count": 8},
    {"stage": "Cotización Enviada", "count": 4},
    {"stage": "Cerrado Ganado", "count": 2}
  ],
  "leads_by_source": [
    {"source": "meta", "count": 10},
    {"source": "google", "count": 6}
  ],
  "leads_by_day": [
    {"date": "2026-05-01", "count": 3},
    {"date": "2026-05-02", "count": 1}
  ],
  "summary": {
    "total_leads": 20,
    "conversion_rate": 0.1,
    "avg_days_to_close": 14.5,
    "leads_this_week": 4
  }
}
```

## Componentes UI

1. **Barra de filtros** — botones de rango (7/30/90/Todo) + dropdown de fuente. Al cambiar, recarga datos y redibuja gráficos.
2. **Tarjetas de resumen** — Total leads, Tasa de conversión (%), Días promedio de cierre, Leads esta semana. Estilo `summary-card` con barra de color lateral.
3. **Gráfico funnel** — barras horizontales ordenadas por etapa del pipeline, colores SAMA.
4. **Gráfico donut** — distribución de leads por fuente, leyenda abajo.
5. **Gráfico timeline** — serie temporal de leads por día con área rellena.

## Cómo verificar

1. Asegurarse de tener leads creados con diferentes etapas y fuentes.
2. Ir a `/crm/<tenant>/analytics/` → aparecen los 4 gráficos con datos.
3. Cambiar rango a "7 días" → los datos se actualizan.
4. Filtrar por "Meta" → solo datos de leads de Meta.
5. Cambiar tema (claro/oscuro) → los colores de los gráficos se adaptan.

## Limitaciones conocidas

- Si no hay pipeline configurado, el funnel muestra solo etapas que tienen leads.
- Los leads sin `LeadSource` no aparecen en `leads_by_source`.
- `avg_days_to_close` es 0 si no hay leads cerrados como ganados.
- No hay exportación a CSV/PDF (para fases posteriores).
