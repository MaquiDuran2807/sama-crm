# Block 12: Comando de reseteo de datos CRM

**Fecha:** Mayo 2026

## Objetivo del bloque

Crear un comando de gestión `reset_crm_data` que permita eliminar todos los datos de las apps CRM y tenants para facilitar entornos de prueba o reset de producción.

## Alcance

- `crm/management/commands/reset_crm_data.py`
- `crm/tests/test_commands.py`
- `docs/blocks/B12.md`

## Orden de eliminación

El comando elimina los datos en el siguiente orden para respetar las restricciones de clave foránea:

1. **LeadActivity** - Actividades de leads (dependen de Lead)
2. **LeadSource** - Fuentes de leads (dependen de Lead)
3. **Lead** - Todos los leads, incluyendo los eliminados suavemente (is_deleted=True)
4. **Contact** - Contactos (dependen de Lead)
5. **CustomField** - Campos personalizados (dependen de Tenant)
6. **PipelineConfig** - Configuración del pipeline (depende de Tenant)
7. **TenantModule** - Módulos activos por tenant (dependen de Tenant)
8. **Tenant** - Inquilinos/klientes

## Uso del comando

### Modo interactivo (predeterminado)

```bash
python manage.py reset_crm_data
```

El comando mostrará una advertencia y solicitará confirmación:
```
⚠️ Esto eliminará TODOS los datos de CRM y tenants. ¿Estás seguro? (sí/no)
```

Solo continuará si el usuario escribe "sí" exactamente.

### Modo automático (para scripts)

```bash
python manage.py reset_crm_data --confirmar
```

Omite la confirmación interactiva.

### Incluir datos de ingesta (opcional)

```bash
python manage.py reset_crm_data --confirmar --incluir-ingesta
```

Esto también eliminará:
- `ChatUser` de la app ingesta
- `DailyTextSummary` de la app ingesta

El comando solicitará confirmación adicional para la ingesta si no se usa `--confirmar`.

## Resultado esperado

Después de ejecutar el comando con confirmación exitosa, se mostrará un resumen:
```
✅ Datos eliminados: 8 leads, 5 contacts, 28 lead_activities, 8 lead_sources, 3 custom_fields, 1 pipeline_config, 3 tenant_modules, 1 tenant
```

Si no había datos para eliminar:
```
✅ No había datos para eliminar.
```

## Casos bordes

- Si no hay datos, el comando termina sin error.
- El comando es idempotente: se puede ejecutar múltiples veces.
- Usa `transaction.atomic()` para garantizar consistencia.
