# Block B25 — Sistema de Tareas (Tasks) para Leads

## User Story

Como usuario del CRM, quiero crear, ver, completar y eliminar tareas para un lead desde la página de detalle. También quiero que el sistema me recuerde las tareas próximas o vencidas, para que nunca perder un compromiso de seguimiento.

---

## Estado Actual

El modelo `LeadTask` ya existe en `crm/domain/models.py`:
- **LeadTask**: lead FK, description, due_date (optional), is_completed, completed_at, created_at.

Los endpoints API ya están parcialmente implementados en `crm/interfaces/views.py`:
- `GET /api/crm/leads/{id}/tasks/` — Lista tareas del lead
- `POST /api/crm/leads/{id}/tasks/` — Crea una tarea
- `PATCH /api/crm/leads/{id}/tasks/{task_id}/` — Actualiza una tarea
- `DELETE /api/crm/leads/{id}/tasks/{task_id}/` — Elimina una tarea

El serializador `TaskSerializer` ya está implementado en `crm/interfaces/serializers.py`.

---

## Mejoras Necesarias

### 1. Ordenamiento de tareas
El listado debe ordenarse por:
1. `due_date` ascendente (nulos al final)
2. Luego por `created_at` descendente

### 2. Completado automático
Al marcar una tarea como completada (`is_completed: true`), debe establecerse automáticamente `completed_at` a la fecha/hora actual.
Al desmarcar (`is_completed: false`), `completed_at` debe become null.

### 3. Tarea Celery para recordatorios
Crear una tarea que envíe recordatorios de tareas próximas o vencidas.

## API Endpoints Documentados

### 1. Listar tareas del lead

**GET** `/api/crm/leads/{id}/tasks/`

**Response (200)**:
```json
[
  {
    "id": 1,
    "description": "Llamar al cliente",
    "due_date": "2026-05-15",
    "is_completed": false,
    "completed_at": null,
    "created_at": "2026-05-10T12:00:00Z"
  },
  {
    "id": 2,
    "description": "Enviar cotización",
    "due_date": null,
    "is_completed": false,
    "completed_at": null,
    "created_at": "2026-05-11T10:00:00Z"
  }
]
```

### 2. Crear tarea

**POST** `/api/crm/leads/{id}/tasks/`

**Body**:
```json
{
  "description": "Llamar al cliente",
  "due_date": "2026-05-15"
}
```

**Response (201)**:
```json
{
  "id": 3,
  "description": "Llamar al cliente",
  "due_date": "2026-05-15",
  "is_completed": false,
  "completed_at": null,
  "created_at": "2026-05-11T10:30:00Z"
}
```

### 3. Actualizar tarea

**PATCH** `/api/crm/leads/{id}/tasks/{task_id}/`

**Body** (ejemplo para completar):
```json
{
  "is_completed": true
}
```

**Body** (ejemplo para cambiar descripción):
```json
{
  "description": "Nueva descripción",
  "due_date": "2026-05-20"
}
```

**Response (200)**:
```json
{
  "id": 3,
  "description": "Llamar al cliente",
  "due_date": "2026-05-15",
  "is_completed": true,
  "completed_at": "2026-05-11T14:30:00Z",
  "created_at": "2026-05-11T10:30:00Z"
}
```

### 4. Eliminar tarea

**DELETE** `/api/crm/leads/{id}/tasks/{task_id}/`

**Response (204)**: Sin contenido.

## Celery: Tarea de Recordatorios

### send_task_reminders

```python
@shared_task
def send_task_reminders():
    """Revisa todas las tareas pendientes y muestra recordatorios en consola
    para aquellas que vencen hoy o mañana, o que ya están vencidas.
    """
```

**Frecuencia sugerida**: Cada 4 horas via Celery Beat.

**Lógica**:
- Tareas no completadas (`is_completed=false`)
- Con fecha de vencimiento no nula
- Que vencen hoy, mañana, o ya están vencidas
- Excluir leads eliminados o cerrados

**Salida** (por ahora consola):
```
[TASK REMINDER] Codensolar SAS | Lead: Juan Pérez | Tarea: Llamar al cliente | VENCE HOY | Due: 2026-05-11
[TASK REMINDER] Codensolar SAS | Lead: María Gómez | Tarea: Enviar cotización | VENCE MAÑANA | Due: 2026-05-12
[TASK REMINDER] Codensolar SAS | Lead: Pedro Ruiz | Tarea: Seguimiento | VENCIDA (hace 2 días) | Due: 2026-05-09
```

## UI: Tareas en lead_detail.html

### Sección "Tareas"

Se agregará una card "Tareas" en la sección de Cambio de Etapa y Notas, o como una nueva sección después de "Etiquetas".

**Elementos de la UI:**

1. **Lista de tareas actuales**: Muestra las tareas del lead como items con:
   - Checkbox para completar
   - Descripción de la tarea
   - Fecha de vencimiento (si existe)
   - Indicador visual de estado (pendiente, completada, vencida)
   - Botón para eliminar

2. **Botón "Agregar tarea"**: Abre un formulario inline o modal para crear nueva tarea.

3. **Nueva tarea**: Formulario con:
   - Input de descripción (obligatorio)
   - Input de fecha de vencimiento (opcional)
   - Botón "Crear"

### Estados visuales

- **Pendiente**: Texto normal, sin indicador de color
- **Completada**: Texto tachado, color gris
- **Vencida**: Texto en rojo o naranja, con icono de warning

## Cómo Testear Manually

### Prerrequisitos
1. Ejecutar `python manage.py seed_dynamic`
2. Navegar a `/crm/{tenant_slug}/leads/{lead_id}/`

### Verificar listado de tareas
1. En la sección "Tareas", ver las tareas existentes.
2. Las tareas con fecha vencida deben mostrarse en rojo.
3. Las tareas completadas deben mostrarse tachadas.

### Crear tarea
1. Click en "Agregar tarea"
2. Ingresar descripción y fecha (opcional)
3. Click en "Crear"

### Completar tarea
1. Click en el checkbox de una tarea
2. La tarea se marca como completada con timestamp en completed_at

### Eliminar tarea
1. Click en el botón de eliminar (×) en una tarea
2. Confirmar en el diálogo

### Verificar recordatorios
1. Crear tareas con diferentes fechas de vencimiento
2. Ejecutar `python manage.py shell` y llamar `send_task_reminders()`
3. Ver la salida en consola
