User Story: As a CRM user, I want to see a user avatar with a dropdown menu in the header so that the system feels personalized and I have access to configuration options.

User Story: As a CRM user, I want the dashboard to use the full width of my screen with minimal margins, so I can see more information at once.

## Key decisions made

- Se centralizó la paleta visual en `themes.css` para que el cambio de tema afecte al header, modales, dropdowns y superficies compartidas desde un único punto.
- El avatar del header se transformó en un dropdown de Bootstrap 5 para mantener compatibilidad con la infraestructura existente de Bootstrap JS sin introducir JavaScript nuevo.
- Se mantuvo el botón de cambio de tema fuera del dropdown para no degradar su acceso rápido.
- El dashboard se hizo más compacto reduciendo padding, gap y el ancho mínimo de columnas, pero sin eliminar el overflow horizontal cuando el espacio real no alcanza.
- Se ajustó el tono de producto y tiempo para que en el tema claro no queden visualmente lavados y el Kanban pueda expandirse mejor en pantallas grandes.
- Se amplió el espacio útil del tablero hacia la derecha reduciendo el padding derecho y bajando el ancho mínimo de las columnas en escritorio.
