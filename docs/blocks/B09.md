# Block 9: Mostrar fuente del lead en la ficha — HU-07

**Fecha:** Mayo 2026

## User Story implementada

### HU-07: Mostrar fuente del lead en la ficha

User Story: As a CRM user, I want to see where each lead came from in the lead detail page, so I know which marketing channel is working best.

## Archivos modificados/creados

- `crm/domain/models.py` — añadido método `get_icon_class()` en `LeadSource` y constante `PLATFORM_ICONS`
- `crm/interfaces/views.py` — `CrmLeadDetailTemplateView` ahora hace `select_related("source")` en la query del lead
- `crm/templates/crm/lead_detail.html` — sección de origen del lead integrada en la card del encabezado (icono de plataforma, UTM fields, landing page, referidor)
- `crm/static/crm/css/dashboard.css` — estilos para `.source-link`
- `docs/blocks/B09.md` — este archivo

## Decisiones clave

- `get_icon_class()` vive en el modelo `LeadSource` (capa domain) para mantener la lógica de mapeo plataforma→icono en un solo lugar.
- `select_related("source")` en la query para evitar N+1 al acceder a `lead.source` en la template.
- Sección de origen integrada dentro de la card del encabezado del lead, con separador visual (`<hr>`) para no agregar una card adicional.
- Si no existe `LeadSource`, se muestra "Sin información de origen" en texto muted.
- Todos los campos UTM se muestran solo si tienen contenido (con `{% if %}`).

## Componentes UI

1. **Icono de plataforma** junto al nombre de la plataforma (usando `get_icon_class()`).
2. **UTM fields** mostrados condicionalmente: Source, Medium, Campaign.
3. **Referido por** — nombre del contacto referidor (si existe).
4. **Landing page URL** — enlace clickeable que abre en nueva pestaña.

## Cómo verificar

1. Crear o editar un lead con `LeadSource` (asignar platform, utm_source, utm_medium, utm_campaign, landing_page_url).
2. Abrir la ficha del lead → debajo de "Categoría" aparece la sección de origen con icono, plataforma, UTM fields y enlace.
3. Crear o editar un lead SIN `LeadSource` → aparece "Sin información de origen" en texto muted.

## Limitaciones conocidas

- No hay sección independiente para el origen; está integrado en la card del encabezado para no sobrecargar la interfaz.
- No se pueden editar los datos de origen desde la ficha (vía admin de Django).
