Este sistema sincroniza mensajes desde Evolution API de forma incremental y paginada, los normaliza con Pandas y los guarda en PostgreSQL evitando duplicados por external_id. Usa IngestionControl para recordar el ultimo timestamp sincronizado por instancia.

Flujo Principal

1) Start sync desde UI o API. 2) Proceso asincrono por job_id. 3) Consulta paginada a Evolution. 4) Deduplicacion e insercion masiva. 5) Actualizacion de cursor incremental.
